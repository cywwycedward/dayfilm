# C4 L4 代码级图

## 适用场景

展开 C4 L3 的一个组件，解释复杂或高风险的实现边界。以类型和对象关系为主时，用 Archify 的 `class`。以函数模块或文件级职责为主时，用 `architecture`。

## 建模内容

标明对应的 L3 组件。选取关键类、接口、类型和函数模块，画出实现、组合或依赖等关系。区分抽象接口和具体实现，只列影响设计或验收的成员。易变细节可按需要从源码提取。

## 绘制步骤

1. 找到需要解释的核心组件和代码位置。
2. 列出参与的关键抽象、实现和关系，注明影响边界的操作签名。
3. 与真实源码以及 L3 的依赖方向核对。

## 示例

Orders 组件中，`OrderService` 依赖 `OrderRepository` 接口。接口公开 `save(order)` 和 `findById(id)`，由 `SqlOrderRepository` 实现。

## 完成检查

每个元素和主要关系均能定位到源码或已确认的目标设计。图中的依赖方向与 L3 一致，关键接口和实现的关系清楚。
