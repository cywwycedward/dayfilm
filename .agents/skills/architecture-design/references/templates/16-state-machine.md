# 状态机图

## 适用场景

用于描述单个实体、聚合或任务的生命周期。用 Archify 的 `lifecycle` 模式制作图。

## 建模内容

- 标出初始状态、主要终止状态、外部事件或命令，以及必须始终成立的不变量。
- 按 `事件 [守卫条件] / 动作` 写迁移。守卫说明能否转换，动作说明转换产生的副作用。
- 按实体分别建模订单、支付等生命周期，明确跨实体的一致性策略。复杂情况按需使用层级状态或并发区域。

## 绘制步骤

1. 选定一个实体，列出状态及来源事件。
2. 为每个状态核对允许的事件、目标状态、守卫和动作，定义非法迁移的可观察结果。
3. 补齐超时、重复事件、竞态和补偿策略，编写合法与非法迁移的验证场景。

## 示例

订单从 `PendingPayment` 收到有效且匹配的 `paymentConfirmed` 时进入 `Paid`，收到 `cancelRequested` 时进入 `Cancelled` 并释放预留。支付消息与取消同时到达时，按已确认的仲裁规则确定结果。

## 完成检查

- 每条迁移能说明事件、守卫和目标状态，适用的副作用可追溯。
- 重复、晚到和非法事件有明确结果，关键不变量对应测试或规则。
