# 部署图与 C4 部署视图

## 适用场景

说明某个环境中的软件实例运行在哪里、怎样连接，以及可用性和运维约束落在哪些节点。

## 建模内容

标出环境、节点、软件实例、网络区、外部依赖、公网入口和存储。注明图描述的是目标部署（As Designed）还是已部署现状（As Built）。用 C4 时，将容器实例映射到部署节点。使用 UML 时，按所选规范表达节点、工件及部署关系。

## 绘制步骤

1. 选定环境，列出与问题相关的节点、实例和运行配置。
2. 追踪网络连接、协议和存储。按需要标注实例数、密钥管理位置、冗余、监控和恢复要求。
3. 以部署配置、基础设施代码或运行时观测核对信息，用 Archify 的 `architecture` 类型制作视图。

## 示例

生产目标部署中，公网负载均衡器将请求转发到私网中的两个 Backend 实例。两个实例访问同一 PostgreSQL 主库。若要画生产现状，使用运行时证据核实实例数和连接。

## 完成检查

每个实例都能对应运行节点，主要入口和网络边界清楚。实例数及容灾声明都有对应的设计依据或运行证据。
