# C4 L3 组件图

## 适用场景

展开 C4 L2 的一个容器，分清内部组件的主要职责、接口和依赖边界。用 Archify 的 `architecture` 绘制。

## 建模内容

选定一个容器，以职责划分组件。组件之间通过公开接口、端口或事件协作。外部容器和系统用边界外的节点表示。组件粒度应能指导源码模块划分，局部实现细节可在代码级视图中展开。

## 绘制步骤

1. 选定一个 L2 容器，沿用名称、边界及相关外部关系。
2. 列出主要组件及职责，确定组件间公开接口和依赖方向。
3. 用源码目录、导入规则和现有接口核对组件划分，检查跨边界调用的入口。

## 示例

Backend API 容器包含 OrderController、Orders、Inventory 和 Payments。OrderController 将订单请求交给 Orders。Orders 分别通过库存和支付公开接口与 Inventory、Payments 协作。Payments 调用容器外的支付网关。

## 完成检查

图中每个内部节点都能映射到该容器内的一组职责或源码。主要依赖能追溯到公开入口，容器内外关系与 L2 一致。
