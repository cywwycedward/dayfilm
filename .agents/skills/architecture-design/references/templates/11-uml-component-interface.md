# UML 组件与接口图

## 适用场景

用于插件、适配器和可替换组件设计。先明确组件稳定的提供接口和需要接口，再用 Archify 的 `architecture` 模式制作关系视图。交付正式 UML 图时，另按 UML 组件图语义核对符号。

## 建模内容

- 标出组件、接口和必要的端口。用 UML 组件符号表示组件，提供接口可用棒棒糖符号，需要接口可用插座符号。
- 为每个接口确认定义方、提供方和消费方。需要按入口区分职责时，标出端口对应的接口。
- 图中只呈现稳定契约和依赖方向。精确契约引用接口定义，具体算法留在实现说明。

## 绘制步骤

1. 确定要替换或独立测试的组件。
2. 从消费方实际需要的能力定义接口，标明提供者、消费者和集成边界。
3. 核对各实现的契约测试和兼容性要求。

## 示例

`Orders` 需要领域接口 `PaymentPort`。`PaymentsAdapter` 提供该接口，并通过 HTTPS 连接外部支付网关。

## 完成检查

- 每个需要接口都能定位到相应契约和预期提供者。
- 替换实现或使用测试替身时，消费方需要的行为仍可通过契约测试。
