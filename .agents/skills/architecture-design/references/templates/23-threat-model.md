# 威胁建模与信任边界图

## 适用场景

评审高价值资产、敏感数据或特权操作经过哪些入口和信任边界，为安全控制和验证明确范围。

## 建模内容

以数据流为基础标注资产、入口、参与者、认证与授权位置以及信任转换点。可用 STRIDE 排查冒充、篡改、抵赖、泄露、拒绝服务和权限提升。系统含 Agent 时，同时评估提示注入、越权工具调用和敏感数据泄露。按威胁 ID 记录场景、影响、控制、验证和残余风险。

## 绘制步骤

1. 找到关键资产、数据流和边界，核对哪些主体可发起各项请求。
2. 评估各入口与跨界流的威胁和影响，关联控制及验证方式。
3. 用 Archify 的 `architecture` 类型画信任区域与跨界连接。需要细化数据传递时，可用 `dataflow` 补充流向和跨界转换点。以风险清单保存具体威胁和残余风险。

## 示例

外部支付平台回调跨越公网和服务端的信任边界。标出回调入口、验签位置和支付记录。风险清单记录「冒充支付平台提交回调」，并关联「签名校验失败时拒绝处理且业务状态不变」的测试。

## 完成检查

每个关键入口和信任转换点都有可核对的安全控制。风险级别、缓解措施、证据和待接受的残余风险可按 ID 追溯。
