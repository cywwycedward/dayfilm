# C4 L2 容器图

## 适用场景

展开 C4 L1 的目标系统，说明哪些应用和数据存储承担运行职责，以及它们如何通信。用 Archify 的 `architecture` 绘制。

## 建模内容

C4 容器指可运行的应用或数据存储。给每个容器标注名称、用途及已确定的技术。用目标系统边界容纳内部容器，保留理解通信所需的用户和外部依赖。通信边标出读写、调用或事件消费等目的及已确定的协议。

## 绘制步骤

1. 沿用 L1 的系统边界，识别可运行应用及存储。
2. 为各容器分配职责，标明存储所有权。
3. 画出通信方向和协议。按需核对跨进程契约及与外部系统的集成。

## 示例

目标系统内有 Web App、Backend API 和 PostgreSQL。顾客经 HTTPS 使用 Web App。Web App 通过 HTTPS/JSON 调用 Backend API，Backend API 通过 SQL 写入 PostgreSQL，并经 HTTPS 调用系统外的支付网关。

## 完成检查

各节点都达到应用或存储的粒度，系统边界与 L1 一致。每条关系能解释通信目的和方向，存储归属与接口契约一致。
