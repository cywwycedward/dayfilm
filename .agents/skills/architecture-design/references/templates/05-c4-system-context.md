# C4 L1 系统上下文图

## 适用场景

向产品负责人或新成员解释目标软件系统的边界、使用者和外部依赖。用 Archify 的 `architecture` 绘制。

## 建模内容

以一个目标软件系统为中心，展示对理解边界有必要的用户角色和外部软件系统。每个节点写明名称、C4 元素类型和一句职责。每条关系写明交互的业务目的，必要时注明协议。外部系统明确标注在边界外。保持系统级粒度，将内部结构留给容器图。

## 绘制步骤

1. 指定目标系统及其职责。
2. 列出直接使用它的人和与它交互的外部系统。
3. 用有方向的关系说明谁为哪个目的发起交互，并与需求或现有集成证据核对。

## 示例

顾客（人）在电商平台（目标软件系统）浏览商品并下单。运营人员（人）通过电商平台管理订单。电商平台向支付网关（外部软件系统）发起支付。

## 完成检查

读者能指出目标系统、使用者和外部依赖，并解释每条关系的业务目的。容器图沿用同一个系统边界。
