# 项目文档索引

按知识领域进入对应目录。各目录索引说明本级文档的职责、查阅时机和内容边界。

| 目录入口 | 职责 | 何时查阅 |
| --- | --- | --- |
| [Agent](agents/INDEX.md) | 提供 Agent 规范、工作流和交接入口，并指向术语与架构决策。 | 选择任务规则、交接工作或定位领域文档时。 |
| [API](api/INDEX.md) | 定位接口契约和机器可读定义。 | 调用、设计或变更接口，评估兼容性时。 |
| [架构](architecture/INDEX.md) | 说明系统结构、模块边界和架构图。 | 分析跨模块依赖、设计复杂变更或维护架构图时。 |
| [数据](data/INDEX.md) | 定位数据模型、Schema、约束和迁移资料。 | 修改数据结构、验证约束或评估数据迁移时。 |
| [工程](engineering/INDEX.md) | 定位开发约定、Git 工作流程、环境配置和测试要求。 | 实施或集成变更、管理工作区、搭建或排查环境、验证变更时。 |
| [运维](operations/INDEX.md) | 定位部署、维护和故障处理资料。 | 发布部署、维护运行环境或排查运行故障时。 |
| [产品](product/INDEX.md) | 记录产品方向、用户需求和产品层面的验收依据。 | 确认产品目标、需求范围或优先级时。 |
| [参考资料](reference/INDEX.md) | 定位工程工作中需复用的外部参考和领域资料。 | 核对术语或查阅相关技术资料时。 |
| [功能规格](specs/INDEX.md) | 指向功能的预期行为和验收标准的权威来源。 | 实现、修改或验证某项功能时。 |
| [项目模板](templates/INDEX.md) | 收录可复用的项目文档模板及适用条件。 | 拟写已有模板覆盖的项目文档时。 |

架构图统一用 `archify` Skill 设计，图种按 `architecture-design` 选择，每张图各占 `docs/architecture/` 下一个文件夹，文件夹名体现图的对象和视图。
