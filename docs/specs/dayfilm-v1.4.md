# Dayfilm v1.4 功能规格（导演工具箱）

在 v1.3 的视觉基础上，把 Dayfilm 从"事后回看"往前推一步：工作时能看见自己在拍什么（HUD），回放时有旁白（字幕），成果能带走（EDL），切日有仪式（片头卡）。视觉规则仍以[视觉语言](../product/visual-language.md)为准。

## R40 导演 HUD

1. 一个 360×148 的无边框置顶小窗，不占任务栏、不抢焦点，默认显示在屏幕右上角（距边缘 24px）。
2. 内容：
   - 顶部发丝线：`● REC` 或 `○ 空闲`（Plex Mono 9px，大写）；
   - 正在拍摄的应用名（Bebas 20px，单行）+ 窗口标题（Inter 10px，单行省略）；
   - 本镜已持续时长（Plex Mono 28px，秒级跳动）；
   - 今日：镜头数 / 剪辑数 / 题材（三组小标签 + 数字，Plex Mono 12px）。
3. 最近 30 分钟的剪辑节奏：30 根 2px 竖条，每分钟一根，高度按该分钟剪辑次数，颜色 `--paper` 18%。
4. 空闲（idleMs ≥ 60s）时顶部显示"空闲"，秒表停止，标题位置显示"离开键盘"。
5. 暂停采样时整窗降为银灰调并显示"已暂停"；采集出错时显示暖红状态点与一行错误摘要。
6. 整窗可拖动；位置写回设置；重启后回到上次位置；位置落在屏幕外时回到默认位置。
7. 单击 HUD 打开主窗口并聚焦。
8. 托盘菜单与设置面板都能开关；默认开启。

## R41 字幕旁白（放映态）

1. 放映态每个镜头在画面下沿上方 24px 显示一行字幕，确定性生成，不调用模型。
2. 组成：`第 N 镜`（Plex Mono 10px，`--paper-dim`）+ 主句（Inter 12px，`--paper`）。
3. 主句按优先级取第一条可用的依据：
   - 当天最长镜头：`这一天最长的一条，你在这里待了 X 分钟。`
   - 剪辑密集的前 10 个镜头：`X 分钟里切出去 Y 次。`
   - 当天第一个镜头：`这一天从这里开始。`
   - 当天最后一个镜头：`这一天的最后一次停在这里。`
   - 其余：`停留 X 分钟。`
4. 字幕淡入 160ms；`prefers-reduced-motion` 时直接出现。

## R42 EDL 导出

1. 导出 CMX3600 格式的 `*.edl`，24fps，供剪辑软件导入当日时间线。
2. 结构：

```text
TITLE: Dayfilm 2026-11-22
FCM: NON-DROP FRAME

001  AX       V     C        20:21:30:00 20:23:12:00 01:00:00:00 01:01:42:00
* FROM CLIP NAME: WindowsTerminal — LZD-20250906UAB: dayfilm
```

3. 时间码为 HH:MM:SS:FF（帧率 24），记录时间从 01:00:00:00 起连续排布。
4. 只导出非空闲镜头；连续镜头之间留真实间隔（用记录时间差体现）。标题为空时用"未命名窗口"。
5. 走保存对话框，扩展名固定 `.edl`；取消返回空串。

## R43 片头卡

1. 切到某一天（进入日视图、且该天有镜头）时播放一次片头：日期、题材、`DAYFILM` 字标依次出现，总时长 1.4 秒，随后淡出。
2. `prefers-reduced-motion` 时不播放。
3. 同一次运行里，同一天只在第一次进入时播放。
4. 片头卡期间界面不接收键盘输入，结束或按 Esc 立即跳过。

## 验收

主 Agent 在构建产物上用 DevTools 协议核对 R40–R43 的正常路径，并导出一次 EDL 与播放一次片头/字幕；纯函数要求单测覆盖：HUD 版式参数、旁白句子选择、EDL 时间码与事件排布、片头卡时长与跳过条件。
