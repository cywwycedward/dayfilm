# Dayfilm v1.2 功能规格（一周电影）

v1.1 让一天看得清，v1.2 回答一个更长的问题：**这一周，我的注意力故事是怎么发展的。** 方向依据见 [ADR 0004](../agents/adr/0004-week-film-direction.md)。

硬约束：**把七天的每日统计相加就能得到的东西，不做。** 周模式的每个元素都必须依赖"跨天"才有意义。

## R30 日 / 周模式

1. 胶片区支持"日"与"周"两种模式切换，默认日模式；周模式替换胶片区域，其它区域（题材、汇总、镜头列表）在周模式下隐藏或替换为周对应的内容。
2. 周模式默认显示当前自然周（周一至周日），可切到上一周与下一周。
3. 数据来源是最近可用日期的 `getDay`；某天读取失败时该天按无数据处理，不影响整周。
4. 周模式下点击任何镜头都能跳到对应的日模式、当天时间轴并选中该镜头。

## R31 七日叙事弧

1. 七天各是一"幕"，每幕显示：日期与星期、当天主线（项目优先，没有项目规则时用进程名）、最长镜头、剪辑次数。
2. **故事线带**：一周内出现过的项目（最多 5 个，按周总时长倒序）各占一行，列为七天，每格表示该项目当天时长（有时长即点亮，亮度随时长对数增长）。
3. 每格可点击：切到该天并选中当天该项目最早的一个镜头。
4. 标记两种剧情：
   - **长主线**：同一主线连续 >= 3 天。
   - **换戏**：某天主线与前一天不同，且当天主线项目在该周的总时长为前二。
5. 没有项目规则时，故事线带用进程名，并显示一句"在设置里加项目规则，故事线会更清楚"。

## R32 周导演评语

1. 一句与**上周**对比的结论，只描述注意力的变化，不评价效率或情绪。
2. 比较三项：最长镜头时长、剪辑密度（每小时剪辑数）、活跃时长。取变化幅度最大的两项写进句子，并给出具体数字。
3. 结论下方可展开"证据"：三项指标本周与上周的数值对照。
4. 上周没有任何数据时，改为"这是第一周，还没有可以对比的上周"。
5. 句子必须是确定性生成（同数据同结果），不调用任何模型。

## R33 本周精选

1. 自动挑选 5–7 个镜头，构成"这一周值得重看的关键场景"。
2. 入选规则（按顺序去重，最多 7 个）：
   - 本周最长的镜头；
   - 本周剪辑最密的 30 分钟窗口里最长的镜头；
   - 各故事线（项目）在本周的第一次登场镜头；
   - 每次"换戏"当天的第一个镜头；
   - 本周最后一个镜头。
3. 每张卡片显示：入选理由、日期、时间、进程、标题、时长；点击跳到该天并选中。
4. 一周没有任何镜头时整块显示空状态文案。

## R34 周视图的数据边界

1. 周起止以本地时区计算，周一为一周开始。
2. 当前周未来日期不参与统计，也不显示为"0 分钟"，只显示为空。
3. 跨周的筛选（项目、检索）不改变周视图的统计口径。

## 验收

主 Agent 在构建产物上用 DevTools 协议核对 R30–R34 的正常路径。纯函数要求单测覆盖：周切分（周一为界、跨月、跨年）、主线判定、故事线分桶、换戏识别、评语句子（含首周分支）、精选挑选（含去重与上限）。
