# Dayfilm v2 功能规格（导演剪辑版与 v2 界面）

v2.0–v2.6 把"一天一部电影"推进到"可以剪、可以配声、可以带走的导演版"：主界面重构、无边框自绘窗口、正片/花絮标记、自动花絮规则、批量标记、周电影只计正片、放映音效、首次运行引导。视觉细节仍以[视觉语言](../product/visual-language.md)与 [DESIGN.md](../../DESIGN.md) 为准；与 v1.x 冲突处按文末[替代关系](#替代关系)以本规格为准。

## R60 无边框窗口

1. 主窗口无系统标题栏（`frame: false`），保留拖边缘缩放（`thickFrame`）与 Win11 圆角；默认 1280×820，最小 960×640。
2. 界面自绘三个窗口按钮：最小化、最大化/还原、关闭。
3. "关闭"与点系统关闭走同一条路径：收进托盘，不退出应用。
4. 最大化状态由主进程在 `maximize` / `unmaximize` 时通知界面，界面据此换按钮图标与 `aria-label`；双击顶部拖动区切换最大化。
5. 三个窗口按钮通道（`window:minimize` / `window:toggle-maximize` / `window:close`）与业务通道一样过来源守卫，窗口不存在时静默忽略。

## R61 导演剪辑版标记

1. 每个非空闲镜头可标记为**正片**（`feature`）或**花絮**（`extra`）；再次点同一个标记即清除。
2. 标记落盘到 `marks.json`，键是镜头开始时刻（毫秒），不是镜号——镜号会随新数据变动。
3. 未标记的镜头按正片算。当日汇总给出 `featureMs` 与 `extraMs`；剧本、海报、PDF、EDL、周电影都按这条口径取数。
4. 标记变更后主进程剔除该日缓存并重算，`set-mark` 直接返回新的 `DayRollup`，界面整份刷新。
5. 镜头行 hover 时出现"正片 / 花絮"两个按钮，当前态高亮；标成花絮的行在标题后带 `花絮`，自动标出的带 `花絮（自动）`。

## R62 自动花絮规则

1. 设置项 `autoExtraUnderSec` 可选 0 / 3 / 10 / 30 秒，默认 0（关闭）。
2. 开启后，**未手动标记**且时长严格小于阈值的镜头算自动花絮（`markSource: 'auto'`）；手动标记优先，哪怕是"正片"。
3. 比较用毫秒，不用四舍五入后的秒数（3.4 秒不会被 3 秒阈值吃掉）。
4. 改阈值时清空汇总缓存，所有已加载日期立即按新规则重算，不需要重建日文件。

## R63 批量标记

1. 顶栏「···」菜单提供三项：把今天 10 秒以下的镜头标为花絮、按设置自动标记、清除今天的全部标记。
2. 单次最多处理 200 个镜头；已经标成花絮的镜头不重复处理。
3. "清除今天的全部标记"需要 4 秒内二次确认，超时重新计时。
4. 阈值配置为 0 时"按设置自动标记"提示先去设置里选阈值；当天没有镜头时三项禁用。
5. 每处理一个镜头调一次 `set-mark`，成功后用最后一次返回的汇总整份刷新；中途失败立即停止并提示。

## R64 导出适配正片/花絮

### EDL

替代 v1.4 R42.2–R42.4 的写法。

1. 只导出非空闲且未标成花絮的镜头；当天有花絮时，头部加一行 `* NOTE: N extra scenes omitted`。
2. clip name 用 ASCII 分隔符 `exe - title`；标题为空写"未命名窗口"；标题里的换行压成空格。
3. 时间码 24fps、帧向上取整；记录轨从 `01:00:00:00` 起，按当天真实间隔顺延（不是紧挨着排）。
4. 走保存对话框，扩展名固定 `.edl`；取消回空路径，写失败抛可读错误。

### PDF

替代 v1.5 R53.2 的内容清单。

1. 镜头表增加"正片 / 花絮"一列：未标记与正片显示"正片"，手动花絮显示"花絮"，自动花絮显示"花絮（自动）"。
2. 汇总区增加一行 `正片 X · 花絮 Y`。

### Markdown 剧本

1. 汇总段在题材之后给出 `正片 X · 花絮 Y`，其余不变。

## R65 周电影只计正片（补充 v1.2）

1. 幕、故事线、剪辑密度、精选、周评语都按 `scene.mark !== 'extra'` 取镜头。
2. 当天有花絮时，活跃时长用 `featureMs`，否则仍用 `activeMs`；这样"只计正片"不会在无花絮的日期改变数字。
3. 花絮占比超过 10% 时，周评语追加一句占比说明。
4. 故事线格的亮度按该行周最大值的**平方根**压缩（替代 v1.2 R31.2 的"对数增长"说法）。

## R66 片场日历题材色相（替代 v1.5 R52.2）

1. 每格颜色 = 题材色相 + 活跃度亮度：长镜头 200°、标准剪辑 45°、快切 48°、跳切风暴 30°，饱和度固定；亮度在题材基色上按当天活跃度在 ±6 内微调。
2. 没有记录的格子用近黑（0°/0%/8%），不当成"0 分钟"的暖白格。
3. 84 天按 12 周 × 7 天排布，周一是行首；今天之后的格子留白。
4. 悬停提示"日期 · 活跃 X 分钟 · 题材"，点击切到该天并关闭日历。

## R67 放映音效

1. 放映态提供"声音：开 / 关"，默认关；开关状态只记在本次会话，不进设置。
2. 两种模式：`projector`（放映机底噪 + 剪辑咔哒）、`cuts`（只有剪辑咔哒）；音量 0–100，存进设置，0 表示完全静音。
3. 声音全部用 WebAudio 合成，不加载音频文件；关闭时释放 `AudioContext`。
4. 开启时显示电平条，取最近约 200ms 的 RMS；关闭或音量为 0 时归零。
5. 换模式或改音量立即生效，不需要重开放映。

## R68 首次运行引导

1. 当"今天已记录的正片时长 < 120 秒"且从未确认过时，在 hero 上显示引导覆盖层。
2. 覆盖层三条说明：只记录窗口名与标题，不截屏不联网；HUD 是置顶小窗；数据只在本机，可随时删除。
3. "知道了，开始拍摄"把 `dayfilm.onboarded=1` 写进 localStorage 并关闭覆盖层；localStorage 不可用时只本次隐藏。
4. "打开设置"直接打开设置抽屉，不写标记。
5. 覆盖层不替换三指标，也不阻塞任何操作。

## R69 导演 HUD 的多屏夹紧（补充 v1.4 R40.6）

1. 首次显示落在光标所在显示器工作区的右上角，距边缘 24px。
2. 保存的位置在任何显示器工作区内时原样使用；落在屏幕外时夹到最近的工作区。
3. 显示器增减、分辨率或缩放变化时重新夹一次，只在 HUD 可见时动作。
4. 拖动结束后 300ms 才写回设置，避免每动一像素写一次盘。

## 验收

主 Agent 在构建产物上核对 R60–R69 的正常路径：无边框窗口三个按钮与双击最大化、两个标记来回切换、自动阈值 3/10/30 秒、批量三项与二次确认、导出一次含花絮的 EDL / PDF / Markdown、周电影在含花絮的一周里只计正片、两种音效模式与电平条、首次运行引导只出现一次、HUD 在双屏间拖动后重启回到可见位置。纯函数要求单测覆盖：`isAutoExtra` 的边界、`applyMarks` 的手动优先与自动回落、批量目标筛选、EDL 的花絮跳过与 NOTE 行、PDF 的标记列与汇总行、周电影的过滤与花絮占比句子、日历题材色阶、HUD 多屏夹紧。
