# Dayfilm v1.5 功能规格

> 有更新：v2 起片场日历按题材色相上色（R66），PDF 增加正片/花絮列与汇总行（R64），见 [v2 功能规格](dayfilm-v2.md)。

v1.5 把"看一天"扩展成"看一段时间、换一种呈现、交给别人"。视觉规则仍以[视觉语言](../product/visual-language.md)为准。

## R50 海报主题

1. 导出海报时可选三种主题：`经典`（现有版式）、`黑色电影`、`极简`。
2. `黑色电影`：近黑底 + 强侧光，只用暖白与一点强调红；胶片带缩到一条细缝，接触印相只留一张最大图，标题用更紧的字距，整体高对比。
3. `极简`：纸白底 + 墨黑字，无胶片带、无接触印相，只保留日期、题材、三项数字、当日之最与一行手记；留白为主。
4. 三套主题共用同一份数据与同一套纯参数（尺寸、位置、字号），主题只决定配色、取舍与版式变体。
5. 主题选择记在本次会话（不写进设置），下次导出默认回到 `经典`。

## R51 双日对比

1. 主界面提供"对比两天"入口：选择两个日期（默认今天与上一个有数据的日期），进入对比视图。
2. 对比视图并排显示两天的：题材与点评、三项数字、素材区间胶片带（各自按自身首尾铺满半宽）、进程前 3。
3. 中间一列显示差异：活跃时长差、镜头数差、剪辑密度差，正负用暖色/银色区分，文案只描述变化不做评价。
4. 点任意一侧的胶片带可回到该天的日视图。
5. 任一天没有数据时，该侧显示空状态，差异列显示"—"。

## R52 片场日历

1. 近 12 周（84 天）的活动日历：7 行（周一至周日）× 12 列，每格一天。
2. 每格按当天活跃时长上色（0 为 2px 暗格，>0 按活跃时长平方根映射到族色暖白），当天有镜头时格内有 1px 内描边。
3. 悬停显示"日期 · 活跃 X 分钟 · 题材"，点击切到该天并关闭日历。
4. 日历以浮层形式出现在胶片上方，Esc 或点空白关闭。
5. 数据按天批量取 `getDay`（每次并发不超过 7 个），加载中显示进度行，已加载的格子先显示。

## R53 剧本 PDF 导出

1. 顶栏"导出剧本"旁提供"导出 PDF"。
2. PDF 用 A4 纵向、背景色随主题（经典=近黑，文字暖白），包含：标题（日期 + Dayfilm 剧本）、手记、题材与点评、三项数字、项目时长（有则显示）、镜头表（时间区间 / 应用 / 标题 / 时长）。
3. 用 Electron `printToPDF` 生成，走保存对话框，扩展名固定 `.pdf`；取消返回空串。
4. 标题与标题里的 HTML 特殊字符必须转义，不允许注入。
5. 生成失败给出可读错误，不崩溃。

## R54 全局快捷键

1. `Ctrl+Alt+D`：显示/隐藏导演 HUD（与设置里的开关同一状态）。
2. `Ctrl+Alt+P`：打开主窗口并进入放映（若已在放映则退出）。
3. 快捷键注册失败（被其它程序占用）时不影响启动，只在托盘提示里说明一次。
4. 退出时注销全部快捷键。

## 验收

主 Agent 在构建产物上核对 R50–R54 的正常路径，并导出一次三主题海报、一次 PDF；纯函数要求单测覆盖：三主题的版式参数差异、对比差异计算（含空侧）、日历色阶与周对齐、PDF HTML 转义与分节、快捷键映射表。
