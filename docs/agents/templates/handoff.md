# Agent 交接模板

需要留档供下一位 Agent 接续实现、评审或集成时，复制下面的模板，删除不适用的条目。发送交接消息时，说明当前结论和记录位置，并确认接收者可以访问相关工作区和证据。分工、交接与消息表达见[多 Agent 协作规范](../policies/collaboration.md)和[沟通规范](../policies/communication.md)。

```markdown
# <任务名称>交接

- **当前结论** <已完成、部分完成或受阻，以及接收者首先需要知道的结果>
- **交接对象** <接收者或负责接续的角色>
- **工作区与版本** <可访问的工作区路径、分支、起始版本，以及当前提交或未提交变更的位置>

## 任务与约束

- **目标与验收条件** <要交付的结果及其完成条件>
- **授权边界** <允许改动的文件或模块、写入归属及相关约束>
- **依赖与依据** <规格、已确认的决策、前置任务和影响接续的假设>

## 已完成的工作

- <说明实际完成的工作及其影响，附文件路径、符号、提交或产出位置>

## 验证

| 命令或检查 | 状态 | 覆盖范围 | 证据或限制 |
| --- | --- | --- | --- |
| <实际执行的命令或待执行的检查> | <通过、失败或未执行> | <已核对的行为、场景或文件> | <输出或报告位置。失败时记录关键错误，未执行时说明原因和影响> |

## 接续事项

- **下一步** <剩余工作、相关位置和责任人>
- **阻塞或待确认** <具体问题、影响、所需决定及负责决定的人>
```
