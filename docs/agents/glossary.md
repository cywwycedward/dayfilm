# 术语表

| 术语 | 含义 | 权威来源 |
| --- | --- | --- |
| 采样（sample） | 一次前台窗口观测记录，含时刻、进程名、标题、空闲时长。 | [数据格式](../data/store-format.md) |
| 镜头（shot） | 同一前台窗口连续停留形成的时间段，>= 3 秒才成镜头。 | [功能规格](../specs/dayfilm-v1.md#r3-镜头切分) |
| 剪辑（cut） | 相邻两个非空闲镜头之间的切换。 | [功能规格](../specs/dayfilm-v1.md#r6-当日汇总与题材) |
| 中场休息（intermission） | 空闲超过 60 秒时切分出的空白镜头。 | [功能规格](../specs/dayfilm-v1.md#r3-镜头切分) |
| 胶片（reel） | 一天中所有镜头按时间排列的整体。 | [产品说明](../product/dayfilm.md#核心概念) |
| 题材（genre） | 由剪辑密度推导出的当日风格标签。 | [功能规格](../specs/dayfilm-v1.md#r6-当日汇总与题材) |
| 剪辑中 | Dayfilm 自身窗口获得焦点时记录的镜头状态，不计入专注。 | [功能规格](../specs/dayfilm-v1.md#r1-采样) |
