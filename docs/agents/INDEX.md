# Agent 规则索引

按任务目标查找工作流，按预计和实际影响查找行为规范及项目知识。已知适用的权威来源时可直接查阅。

## 本级入口

| 入口 | 职责与查阅时机 |
| --- | --- |
| [工作流](workflows/INDEX.md) | 按功能开发、缺陷修复、测试、评审、重构或文档变更选择任务流程。 |
| [行为规范](policies/INDEX.md) | 按上下文、授权、沟通、写作、治理或协作需求查找适用规则。 |
| [Agent 模板](templates/INDEX.md) | 跨阶段或工作区交接需要留档时，查找记录模板。 |
| [架构决策记录](adr/INDEX.md) | 追溯既有架构决策的理由或核对其状态时，查找相关 ADR。 |
| [领域文档](domain.md) | 使用工程 Skill 查找或维护术语和 ADR 时，确认文档位置及编号方式。 |
| [领域术语表](glossary.md) | 需要确认项目术语的含义和用法时查阅。 |
| [Issue 跟踪配置](issue-tracker.md) | 查阅、发布或维护 Issue、功能规格及其依赖关系时，定位跟踪器和操作方式。 |
| [Issue 分诊标签](triage-labels.md) | 分诊 Issue 或发布待办时，按 Skill 角色查找现有 GitHub 标签。 |

查找规格、架构、接口契约或工程约定的权威来源时，查阅[项目文档索引](../INDEX.md)。
