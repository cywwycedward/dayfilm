# ADR 0002 存储：按日 JSONL 文件

- 状态：已采纳
- 日期：2026-11-22

## 背景

需要保存前台窗口采样。每 2 秒一条，单日约 4.3 万条、约 4 MB。可选方案：SQLite（`better-sqlite3` 需要与本机 Node/Electron ABI 匹配的原生模块）、自建二进制格式、按日 JSONL。

## 决策

按本地日期分文件，每行一个 JSON 采样，只追加。

## 理由

- 零原生依赖：安装与打包不需要编译链，也不会因 Electron ABI 变化而失效。
- 崩溃安全边界清楚：进程意外退出最多丢最后一行，不会写出半截数据库。
- 可调试：用户能直接打开文件核对内容，符合"只在本地、用户可见"的产品原则。
- 容量可控：单日 4 MB，30 天约 120 MB；第二里程碑加保留期清理。

## 后果

- 全量读取一天需要解析数万行，切分成本集中在读取阶段；第二里程碑改为增量聚合与按需加载。
- 检索是线性扫描；单日规模下可接受，跨月检索需要索引，届时再评估是否引入 SQLite。
