# Dayfilm 控件参考研究

短分段、命令菜单、值选择和抽屉分区各有自己的键盘路径，即使共用琥珀选中态，也要让焦点、已选值和展开状态可分别辨认。以下对照官方示例、固定提交源码和 Dayfilm 当前渲染层，供组件设计与验收参考。尺寸、字号和颜色沿用 Dayfilm 的设计依据。[设计系统](../../DESIGN.md) · [视觉语言](visual-language.md)

## 分段与放映

- **日／周、放映速度与音效模式。** Primer 的 Preview／Raw／Blame 示例把分段做成带名称的列表，每项为原生按钮。源码用 `aria-pressed` 和 `data-selected` 表达同一选中值，`Tab` 逐项进入，`Enter` 或空格激活。再次激活当前项仍会调用配置的 `onChange`，选中值保持原样。Dayfilm 已用按压按钮表达这些短分段，可沿用此键盘路径，以焦点环区分当前焦点与琥珀实底的已选项。同样外形的 Radix 单选 Toggle Group 使用游走焦点，重按当前项默认会给出空字符串。速度等始终需要有效值的控件要验证重按后仍有选中项。[Dayfilm 标记](../../src/renderer/index.html) · [Primer 示例](https://primer.style/product/components/segmented-control/) · [Primer 键盘说明](https://primer.style/product/components/segmented-control/accessibility/#keyboard-navigation) · [Primer 容器源码](https://github.com/primer/react/blob/7cf064cd860065c0614d575d78fe1632a0634e5d/packages/react/src/SegmentedControl/SegmentedControl.tsx#L203-L249) · [Primer 按钮源码](https://github.com/primer/react/blob/7cf064cd860065c0614d575d78fe1632a0634e5d/packages/react/src/SegmentedControl/SegmentedControlButton.tsx#L42-L57) · [Radix 单选实现](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/toggle-group/src/toggle-group.tsx#L91-L116)
- **放映进度、音量和开关。** Radix Slider 的示例分别渲染轨道、进度和滑块，源码为滑块提供当前值和上下限，处理方向键、`Home` 和 `End`，并区分值变化与提交。Dayfilm 已用原生范围输入，放映进度在 `input` 时定位。可用同一套按键检查起止值和步长，并验证轨道变细后焦点环仍可见、时间值易读。Radix Switch 用固定标签、`role="switch"` 和 `aria-checked` 表达同一个二值状态，`Space` 或 `Enter` 切换。Dayfilm 的设置行已有带标签的原生复选框，可核对标题、视觉旋钮、可访问状态与保存结果保持一致。[Slider 示例](https://www.radix-ui.com/primitives/docs/components/slider) · [Slider 键盘源码](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/slider/src/slider.tsx#L264-L292) · [Switch 示例](https://www.radix-ui.com/primitives/docs/components/switch) · [Switch 源码](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/switch/src/switch.tsx#L155-L180) · [Dayfilm 标记](../../src/renderer/index.html) · [Dayfilm 事件实现](../../src/renderer/src/app.ts)

## 菜单与值选择

- **导出／更多。** Primer 的 ActionMenu 示例展示命令和单选菜单项。源码将选中状态映射为 `aria-checked`，并在常规锚定菜单中将 `Tab` 作为关闭路径。Radix 的图标按钮示例用 `aria-expanded` 同步展开状态，键盘可用 `Enter`、空格或 `↓` 打开，源码阻止 `Tab` 在菜单内导航，并在未与外部交互时归还焦点。Dayfilm 已支持打开后聚焦首项、`↑/↓` 循环和 `Esc` 返回触发器。APG 规定 `Tab/Shift+Tab` 离开并关闭菜单，可作为 Dayfilm 的验收参考。另需检查执行命令后的焦点去向，以及命令打开另一层时焦点是否进入新层。用普通菜单项表达导出命令，只有持续显示当前值的单选菜单才需要已选状态。[Primer 示例](https://primer.style/product/components/action-menu/) · [Primer 关闭与选中源码](https://github.com/primer/react/blob/7cf064cd860065c0614d575d78fe1632a0634e5d/packages/react/src/ActionMenu/ActionMenu.tsx#L309-L349) · [Radix 示例](https://www.radix-ui.com/primitives/docs/components/dropdown-menu) · [Radix 触发器](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/dropdown-menu/src/dropdown-menu.tsx#L110-L144) · [Radix 焦点归还](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/dropdown-menu/src/dropdown-menu.tsx#L188-L208) · [Radix 菜单按键](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/menu/src/menu.tsx#L575-L600) · [APG 菜单键盘模式](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/#keyboardinteraction) · [Dayfilm 菜单实现](../../src/renderer/src/app.ts)
- **保留期等固定选项。** Radix Select 的水果示例用 `combobox` 触发器和 `listbox`，把实际焦点移到选项上，并提供键入匹配与关闭后焦点归还。Dayfilm 与 APG 的只选型示例采用同一种焦点模型，DOM 焦点留在触发按钮，通过 `aria-activedescendant` 指向高亮项。Dayfilm 的 `Enter/Space` 提交、`Esc` 保留旧值、失焦关闭路径应单独验收。APG 示例的 `Tab` 或失焦会提交高亮项，Dayfilm 当前失焦只收起。检查打开时先高亮已选项、键盘移动时原值保留、高亮行滚入可见范围，以及面板在窗口边缘翻转后仍可操作。[Radix 示例](https://www.radix-ui.com/primitives/docs/components/select) · [Radix 选项聚焦](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/select/src/select.tsx#L812-L825) · [Radix 归还焦点与列表键盘源码](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/select/src/select.tsx#L898-L959) · [APG 只选型下拉示例](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/) · [Dayfilm 下拉实现](../../src/renderer/src/select.ts)

## 设置抽屉

- **外层模态与内层分区。** Fluent OverlayDrawer 默认采用模态 Dialog，Dialog 源码负责初始焦点和限制焦点范围，Surface 处理 `Esc`。默认故事把标题、关闭按钮和可滚动内容拆开，并显式标记焦点归还的来源与目标。Dayfilm 已有 `role="dialog"`、Tab 循环和关闭后回到设置按钮的处理。打开抽屉时应检查初始焦点在当前可见分区内。当前代码固定尝试聚焦采集分区的保留期，所以也要测从项目等其他分区重开，以及内层下拉打开时第一次 `Esc` 是否只收起下拉。[Fluent Drawer 指南](https://fluent2.microsoft.design/components/web/react/core/drawer/usage) · [Fluent 默认示例源码](https://github.com/microsoft/fluentui/blob/b9b6302a1b00e739e18c799cd1e74a62cd2a7ea7/packages/react-components/react-drawer/stories/src/Drawer/DrawerDefault.stories.tsx#L57-L105) · [Drawer 实现](https://github.com/microsoft/fluentui/blob/b9b6302a1b00e739e18c799cd1e74a62cd2a7ea7/packages/react-components/react-drawer/library/src/components/OverlayDrawer/useOverlayDrawer.tsx#L35-L68) · [Dialog 焦点](https://github.com/microsoft/fluentui/blob/b9b6302a1b00e739e18c799cd1e74a62cd2a7ea7/packages/react-components/react-dialog/library/src/components/Dialog/useDialog.ts#L24-L51) · [Dialog 关闭](https://github.com/microsoft/fluentui/blob/b9b6302a1b00e739e18c799cd1e74a62cd2a7ea7/packages/react-components/react-dialog/library/src/components/DialogSurface/useDialogSurface.ts#L63-L73) · [Dayfilm 抽屉实现](../../src/renderer/src/app.ts)
- **分区切换。** Radix Tabs 的 Account／Password 示例提供面板切换。源码以 `aria-controls` 和 `aria-labelledby` 连接标签与面板，支持纵向方向键以及自动或确认后激活。Dayfilm 当前用分区按钮和隐藏面板。如果采用纵向标签页语义，`↑/↓` 应在五个标签间移动，`Tab` 再进入当前面板。只有内容能即时显示时才适合随焦点自动切换。960×640 下检查分区标签、焦点环、内容滚动与关闭入口同时可达。[Radix Tabs 示例](https://www.radix-ui.com/primitives/docs/components/tabs) · [Tabs 实现](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/tabs/src/tabs.tsx#L129-L227) · [面板关联](https://github.com/radix-ui/primitives/blob/eb3a2b7091293e27df8f9ba906632d8daa3d81a3/packages/react/tabs/src/tabs.tsx#L254-L278) · [APG Tabs 键盘模式](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/#keyboardinteraction) · [Dayfilm 设置标记](../../src/renderer/index.html)
