# Dayfilm 产品说明

## 一句话

Dayfilm 把你一天里注意力落在哪些窗口上，剪成一部可以回放、可以检索、可以品评的电影。

## 问题

市面上的时间记录工具都长成报表：柱状图、饼图、时长排行。数据能看，但看不出一天"像什么"。人对一天的记忆本来就是叙事性的——上午有一段长专注，午后被消息切得稀碎。报表把这个叙事拆掉了。

Dayfilm 保留叙事：一天是一卷胶片，连续待在一个窗口是**一个镜头（shot）**，切换窗口是**一次剪辑（cut）**，长时间离开是**中场休息（intermission）**。于是"今天专注得怎么样"这个问题，可以用电影语言回答："今天有一个 47 分钟的长镜头，之后是 200 次跳切。"

## 用户

单人使用、Windows 桌面、关心自己注意力去向的开发者或写作者。不需要账号，不联网，数据只在本机。

## 产品原则

1. **只在本地。** 不采集屏幕像素、不采集键盘内容、不联网。只记录前台窗口的进程名、标题和时间戳。
2. **一眼可见。** 打开就看到"现在正在拍摄什么"和今天这卷胶片的形状，不需要先配置报表。
3. **电影语言优先。** 统计口径用镜头、剪辑、中场解释，而不是纯时长堆叠。
4. **安静的常驻程序。** 空闲时不打扰，自身开销可忽略。

## 核心概念

| 概念 | 含义 |
| --- | --- |
| 采样（sample） | 每 2 秒记录一次前台窗口的进程名、标题、空闲时长。 |
| 镜头（shot） | 连续处于同一窗口的一段时间，>= 3 秒才成镜头。 |
| 剪辑（cut） | 两个相邻非空闲镜头之间的切换。 |
| 中场休息（intermission） | 空闲超过 60 秒时插入的空白镜头。 |
| 胶片（reel） | 一天的镜头序列，按时间轴铺开。 |
| 题材（genre） | 由剪辑密度推导出的当日风格，例如"长镜头""跳切风暴"。 |
| 项目（project） | 用户定义的"故事线"：标题或进程名命中关键词的镜头归入同一项目。 |
| 导演手记（note） | 用户给某一天写的一句评语，进剧本与海报。 |
| 高光（highlight） | 自动挑出的三个当日之最：最长镜头、最密 30 分钟、最长进程。 |
| 海报（poster） | 把一天渲染成 1600×1000 的图片，题材、胶片缩略、数据与手记在一张纸上。 |
| 叙事弧（arc） | 一周七天的"幕"：每天的主线、最长镜头与剪辑节奏，连起来看剧情怎么走。 |
| 换戏 / 回归 | 主线被别的项目抢走 / 之后重新夺回，周视图里用标记区分。 |
| 周精选（week picks） | 一周里值得重看的关键镜头，可点击回到当天时间轴。 |
| 导演 HUD | 360×148 的置顶小窗：正在拍什么、这一条拍了多久、今天的节奏柱。 |
| 旁白（narration） | 放映时给每个镜头的一句解说，按规则确定性生成。 |
| EDL | 把一天导出成 CMX3600 剪辑表，可导入 DaVinci Resolve / Premiere 当日志时间线。 |
| 正片 / 花絮 | 镜头的手动标记：正片计入专注时长，花絮只作参考，仍保留在胶片上。 |
| 自动花絮 | 短于设置阈值的未标记镜头自动算花絮，手动标记优先。 |
| 放映 | 单日时间轴的 16:9 大画面回放，带旁白字幕、音效电平与进度条。 |
| 放映音效 | 放映时的放映机底噪与剪辑咔哒，可开关、可调音量，声音全部实时合成。 |
| 片场日历 | 近 12 周的活跃度日历，按当天题材的色相上色。 |
| 双日对比 | 并排两天并给出差异的视图，用于回答“这两天哪里不一样”。 |

## 版本范围

- **MVP（第一里程碑）**：录制、落盘、当日胶片、实时状态、检索、可回放、可导出剧本。只跑得通、看得见，不追求防御性设计。
- **可交付版本（第二里程碑）**：安全与隐私边界、异常与崩溃恢复、性能与容量、独立测试与压力测试、打包分发、完整运维文档。
- **v1.1 导演版**：时间轴缩放与周视图让"看清"成为可能；项目标签把散落的进程收成故事线；导演手记、高光与海报导出把"一部电影"从比喻做成可带走的成品。
- **v1.2 一周电影**：七天排成七幕，故事线带标出延续、换戏与回归，配一句与上周对比的周导演评语，再挑出本周值得重看的 5–7 个镜头。方向由外部裁决确定，见 [ADR 0004](../agents/adr/0004-week-film-direction.md)。
- **v1.3 视觉重做**：场记板剧照、放映模式、自托管字体、密度直方图、海报两栏、图标与三态托盘。
- **v1.4 导演工具箱**：导演 HUD 让"这一条拍了多久"边工作边可见；放映时有纪录片式旁白字幕；一天可以导出成真正的 CMX3600 EDL 交给剪辑软件；切日有 1.4 秒片头卡。
- **v1.5 导演工具箱之二**：海报三主题、双日对比、片场日历、剧本 PDF、全局快捷键。
- **v1.6 界面铬**：滚动条、滑块、输入框、按钮、面板与焦点环按概念图重做；双日叠片。
- **v2.0–v2.6 导演剪辑版**：主界面重构（场记板 hero + 竖向胶片脊柱 + 右栏）、无边框自绘窗口、正片/花絮标记与批量标记、自动花絮规则、周电影只计正片、放映音效、首次运行引导、HUD 多屏夹紧。行为规格见 [v2 功能规格](../specs/dayfilm-v2.md)。

各版本的逐条验收条件见[功能规格索引](../specs/INDEX.md)。
