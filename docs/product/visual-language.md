# 视觉语言

Dayfilm 的视觉权威。界面、剧照、海报、图标都按这份文档执行；改动先改这里。

### 复盘工作台（v4.3）

- 日视图的阅读顺序为题材与判词 → 当前窗口与剧照 → 手记与记录证据（上一集、中场、发现）→ 高光。证据保留原有点击与键盘路径，不折叠。题材为 80px，空态 56px；剧照至少 168px，短窗口允许主区自然滚动，不把证据裁掉。
- 周视图日列的日期、主线和指标纵向排布，徽标使用可换行的独立行，不跨列。设置用清晰标题和单边选中线，项目编辑与删除保留独立焦点，删除在悬停和聚焦时提示危险语义，添加键与输入成行。
- 不新增运行时位图或依赖；概念图只作设计证据。验收在 1280×820 与 960×640 使用同一份模拟记录，检查剧照、完整证据可达性、周徽标边界及设置控件。

现状问题（v1.2 时）：剧照是把 `exe|title` 哈希成渐变角度与几何母题，**不表达任何信息**，同一应用的不同窗口只是色相微差，看起来像随机色块；播放只是让播放头移动，没有"放映"的感觉。这两条已在 v1.3 及之后解决，留作背景。

## 一、总原则

1. **电影感来自版式，不来自装饰。** 用排印、留白、发丝线、字重对比建立层次，不用卡片阴影、圆角面板、彩色渐变。
2. **每一帧都要有信息。** 剧照必须能读出"哪个应用、什么窗口、第几镜、多长"，不再是抽象图案。
3. **颜色是索引，不是装饰。** 颜色只用来标识"哪个应用族"，并且只出现在校准过的位置（边条、齿孔、下划线），不做大面积填充。
4. **克制。** 一屏最多一个视觉重点；同一屏里的暖色不超过两处。

## 二、字体

三套自托管字体（`src/renderer/src/assets/fonts/`，OFL 授权，随包分发）：

| 用途 | 字体 | 字重 | 用法 |
| --- | --- | --- | --- |
| 展示（应用名、题材、大数字） | Bebas Neue | 400 | 全大写、`letter-spacing: 0.08em`，只用于拉丁字符 |
| 正文与控件 | IBM Plex Sans | 400 / 500 / 600 / 700 | 中文回落到 `"Microsoft YaHei UI"`；v2.2 起取代 Inter，四个字重都有文件，不再有伪加粗问题 |
| 时刻与时长 | IBM Plex Mono | 400 / 500 | `font-variant-numeric: tabular-nums` |

字号阶梯（px）：10 / 11 / 12 / 14 / 18 / 24 / 32 / 56。只用这一组。
小标签统一 `font: 10px "IBM Plex Mono"; text-transform: uppercase; letter-spacing: 0.18em; opacity: .45`。

## 三、颜色

```text
--ink        #0a0b0d   页面底色
--charcoal   #12141a   面板底色
--graphite   #1b1e26   分隔与静默块
--paper      #ece7dc   主文字（暖白，不用纯白）
--paper-dim  rgba(236,231,220,.55)
--silver     #8d939e   次要信息、中场休息
--amber      #e8b45a   焦点、正在拍摄、播放
--red        #b8524a   错误
```

**应用族色**（12 个色相带，每带 30°，`hsl(h, 24%, 38%)`）：由进程名哈希到色带，只用于剧照边条与项目行的小圆点。同一进程在全应用永远同色。

## 四、剧照（scene still）

剧照是**场记板式的一帧**，不是图案。内容取自已确定的场景数据，不用随机数决定构图。

### 三种尺寸

| 形态 | 触发条件 | 保留元素 |
| --- | --- | --- |
| 完整帧 | 宽 ≥ 120px 且 高 ≥ 64px | 底纹 + 齿孔 + 应用名 + 标题 + 时间码 + 镜次 + 族色边条 + 颗粒 |
| 紧凑帧 | 56px ≤ 宽 < 120px | 底 + 族色顶条 2px + 应用名（Bebas，按宽度 12–16px 自动缩放）+ 右下角镜次 |
| 细缝 | 宽 < 56px | 只用族色在 35% 不透明度填充 + 顶部 2px 暖白高亮条；没有文字、没有齿孔 |

### 完整帧的版式（按 16:9 比例内缩 8px 安全区）

- 底色：`--charcoal`，自上而下 6% 的暗渐变；1px 内描边 `rgba(236,231,220,.08)`。
- 左缘：3px 族色竖条，贯穿上下。
- 底部与顶部：各 5px 的齿孔带——每隔 14px 一个 6×3px 的圆角孔，颜色 `rgba(10,11,13,.85)`，上下都画，形成胶片框。
- 应用名：Bebas，24px（帧高 < 90px 时 18px），全大写，`--paper`，`letter-spacing: 0.08em`。
- 标题：Plex Sans 400，10px，`--paper-dim`，单行省略号，距应用名 6px。
- 左下：时间码 `HH:MM–HH:MM`，Plex Mono 9px，`--paper-dim`。
- 右上：镜次 `#07`，Plex Mono 9px，`opacity: .4`。
- 颗粒：确定性噪声（种子来自日期+镜次），透明度 4%，只画一次到离屏 canvas 再复用。
- 中场休息：不画族色条与齿孔，改用 45° 细斜纹（间距 6px，`rgba(141,147,158,.16)`），应用名位置写"中场休息"。

### 硬要求

- 同一场景在胶片、缩略图、放大帧、海报里必须渲染成同一张图（用同一次绘制结果缓存位图，按目标尺寸缩绘，不按尺寸重排版）。
- 全部绘制在 canvas，字号必须 `Math.round`，避免模糊。
- 文本必须在 `document.fonts.ready` 之后绘制，否则会用回落字体。

## 五、放映（playback）

播放不是"播放头前进"，是进入放映状态：

- 按 `播放` 后，胶片收成底部 64px 的细带，中间出现 16:9 的大画面（完整帧放大渲染），下方一行：镜次、应用名、标题、时长。
- 场景切换用 120ms 交叉淡入，切换瞬间画面整体向左位移 4px 再回位（模拟走片）。
- 画面四周有滚动的齿孔带（CSS 动画，`transform: translateX`，每秒 14px × 倍速系数，倍速越高越快）。
- 右上角常驻 `SHOT 07 / 33`（Plex Mono），右下角 `20:38`。
- 倍速 600x/3600x 时，画面右上角出现"每秒 N 次剪辑"读数；每次剪辑让画面左缘闪一帧 2px 暖色（80ms）。
- 底部细带用族色块表示已播放区间，播放头是一条 1px 暖白竖线。
- `Esc` 退出放映，回到日视图。
- 声音：默认关闭。开关打开后用 WebAudio 生成放映机底噪（2 秒噪声循环过 320Hz 带通，音量极低）与每次剪辑的一声短促咔哒；另有“仅剪辑”模式与电平条。不依赖任何音频文件。

## 六、版式

- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 分区之间用 1px `rgba(236,231,220,.07)` 发丝线分隔，**不用卡片边框、不用圆角面板**（设置抽屉除外）。
- 顶栏：左侧 `DAYFILM`（Bebas 18px）+ 副标题（Plex Sans 10px，`--paper-dim`）；右侧控件按 importance 从右到左排列。
- 大标题（题材）：v2 主界面 hero 里是 128px（拉丁 Bebas，中文系统 900，字距 0.02em，见 [DESIGN.md](../../DESIGN.md)）；对比等次级视图用 44px。其下紧接一行 12px 说明。
- 数据标签一律用"小标签 + 大数字"的上下结构，数字用 Plex Mono 24px，标签 10px 大写。
- 所有可点元素有 2px 暖色焦点环与 `:focus-visible`；hover 只改透明度，不改布局。

## 七、海报与图标

- 海报底色 `--ink`，标题区用 Bebas 64px，胶片缩略用完整帧等比缩绘，底部一行 Plex Mono 时间码，右下角 `DAYFILM` 字标。
- 应用图标：单帧胶片 + 中央一条暖白曝光缝；16px 下必须只剩"深底 + 一条亮缝"仍可辨认。托盘图标三态（正常/暂停/出错）同形不同色：暖白、减半亮度、暖红。

## 八、界面铬（chrome）

依据 2026-11-23 的外部概念图（ChatGPT 项目 `dayfilm` 会话「生成UI概念图」，六条规范）。用户原话是"边框和滑动框太丑"，所以这一节取代此前零散的边框规则。

1. **滚动条**：宽 6px；轨道全透明；滑块 `rgba(236,231,220,.16)`，悬停 `.34`，圆角 3px，最小长度 24px；容器悬停时才显现（未悬停时滑块接近隐形）。不在页面主滚动区使用系统默认滚动条。
2. **滑块（scrubber / range）**：轨道 2px `rgba(236,231,220,.14)`；已播放段填 `--amber` 55%；拇指 6px 实心 `--paper`，拖动时 8px 且变 `--amber`；过渡 120ms。
3. **输入框**：不要四边框。仅底部 1px 发丝线 `rgba(236,231,220,.16)`，背景透明；聚焦时底线变 `--amber`，不加外框。
4. **下拉框**：同样只用底线；自绘 10px 三角或竖线作为指示，去掉系统外观（`appearance: none`）。
5. **按钮**：分三级——主按钮（琥珀实底 + 近黑字，无边框）、次按钮（纯文字，悬停加下划线）、图标按钮（无边框，悬停 4% 底色）。所有按钮取消 1px 边框，圆角 2px。
6. **面板与浮层**：1px 发丝线 `rgba(236,231,220,.08)` + 底色比背景亮 5%（`#14161c`）；不画圆角大框，层级靠"色调抬升"而不是阴影；仅真正浮起的层用 `0 24px 64px rgba(0,0,0,.55)`。
7. **焦点环**：`:focus-visible` 统一 2px `--amber` 描边 + 2px 偏移（画在元素外侧）。
8. **剧照卡片**：不再画 1px 外框，改用 1px 内发丝线（`inset 0 0 0 1px rgba(236,231,220,.06)`）+ 色调差；选中态才出现 1px 暖白内描边。

## 九、验收方式

改视觉后必须提供四张截图：日视图（有数据）、放映中、周视图、海报导出结果；三者共用同一套剧照渲染。文字类改动要在 1280×820 下逐字检查是否溢出或换行错位。
