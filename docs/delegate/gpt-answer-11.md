# 外部裁决 11：设置抽屉改成「分区导航 + 单分区内容」

提问原文见 `ask-gpt-11.txt`，附 3 张当前设置面板截图。返回是纯图，落地版存为 `docs/product/assets/settings-drawer-concept-v3b.png`。

## 概念板给出的结构

- **布局**：抽屉 520 = 导航 124 + 内容 396；左侧分区导航（5 项，13px），右侧单分区内容。
- **5 个分区**：采集（保留期 + 脱敏）· 项目（规则 + 候选）· 模型 · 常驻（开关 + 自动花絮）· 系统（音效 + 数据 + 退出）。
- **字号层级**：NAV 13 / TITLE 22 / ROW 14 / MONO 12。
- **项目分区**：故事线候选行（名称 + 镜头数 + 「收为项目」），已有项目行（名称 + 关键词标签 + 词数 + 镜头数 + 编辑）。
- **模型分区**：启用开关 + 接口 / 模型 / KEY + 保存 / 测试连接 / 清除 KEY + 「发送摘要」。
- **右栏统计**：三个数字改成三行紧凑表格（图标 + 标签 + 值 + 单位）。

## 落地时照做与改动的部分

| 项 | 落地 |
