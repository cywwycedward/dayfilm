# 任务说明书：界面实现（df-ui）

## 目标

做出 Dayfilm 的呈现层：一屏之内同时看到"现在在拍什么"和"今天这卷胶片长什么样"，并且能回放、检索、切日期、导出。视觉要达到"看一眼就记住"的水准，不是仪表盘。

## 权威资料

- 产品定位与原则：`docs/product/dayfilm.md`
- 功能规格：`docs/specs/dayfilm-v1.md`（R4、R5、R6、R7、R8、R9 的界面部分）
- 契约：`docs/api/ipc-contract.md`、`src/shared/types.ts`、`src/shared/ipc.ts`
- 设计方法：先读 `.agents/skills/impeccable/SKILL.md`，按其中的设计审视方法组织视觉决策。

## 可写范围

- `src/renderer/**`
- `tests/renderer/**`
- `docs/delegate/status-ui.md`

不要改动 `src/main/**`、`src/shared/**`、`package.json`、构建配置、其他文档。需要改契约或加依赖时写进状态记录并停止等待指示。

## 技术约束

- 原生 DOM + CSS + Canvas，不引入任何框架或运行时依赖，不联网（CSP 已限定 `default-src 'self'`，禁止远程字体与图片）。
- TypeScript 严格模式，不用 `any`。
- 只通过 `window.dayfilm` 取数据。**必须**在 `window.dayfilm` 不存在时回退到本地 mock（`src/renderer/src/mock.ts`，用确定性伪随机生成一整天的合理数据），这样界面可以独立开发与演示。
- 性能：回放时只重绘必要的 canvas 区域；避免每帧读写 DOM 布局。

## 必须交付

### 1. 信息结构

一屏，自上而下：

1. **顶栏**：产品名 `DAYFILM`、日期选择（只列出有数据的日期，默认今天）、检索输入框、导出按钮、采集状态指示（正常 / 采集中断的显眼提示）。
2. **正在拍摄条**：`正在拍摄：Code · dayfilm - Visual Studio Code` 或 `空闲中`；右侧显示已持续时长，每秒跳动。
3. **胶片（reel）**：横向铺满 00:00–24:00 的时间轴。每个镜头是一段带程序化"剧照"的色块，宽度按真实时长比例；中场休息用明显的留白/条纹区分。支持点击选中、键盘左右移动、hover 提示（起止时间、时长、标题）。刻度标出 00/06/12/18/24 时与"现在"的位置。
4. **回放条**：播放/暂停 + 倍速（60x / 600x / 3600x）+ 进度拖拽；播放时"当下"指示器沿胶片推进，当前镜头放大展示剧照与标题。默认暂停在现在。
5. **当日汇总面板**：题材（`长镜头`/`标准剪辑`/`快切`/`跳切风暴`）作为大号主视觉 + 一句点评；活跃时长、镜头数、剪辑数、最长镜头；进程时长排行（前 5，横条）。
6. **镜头列表**：按时间正序，每行：剧照缩略、起止时间、进程、标题、时长。检索时切换为结果列表（最多 200 条），点击定位到胶片。

### 2. 程序化剧照

每个镜头根据 `hash(exe + '|' + title)` 生成确定性的视觉：渐变角度、配色、几何形状（细线/圆/条纹等）由哈希决定，画在 canvas 上。要求：同一镜头每次渲染一致；视觉上能区分不同进程族（例如不同 exe 取不同色相带）；整体克制、有电影感，不要花哨到影响阅读。

### 3. 视觉方向

- 影院气质：近黑背景、浓郁但低饱和的分区色、细字距的大写小标题、克制的动效（150–250ms）。
- 用 CSS 变量组织颜色与间距，浅色模式可选（不强制）。
- 提供空状态（"还没有拍摄任何素材"）与采集错误横幅。
- 键盘可达：胶片可聚焦、方向键移动、Enter 打开详情；可见焦点环；`prefers-reduced-motion` 时关闭动效。
- 中文界面，术语沿用规格中的"镜头/剪辑/中场休息/题材"。

### 4. 测试（`tests/renderer/**`）

纯函数部分（哈希、时间轴布局映射、时长格式化、mock 数据生成）写成独立模块并测试：同一输入稳定、时间轴比例正确（00:00→0，24:00→1）、空数据不产生 NaN。

## 自检

```powershell
npm run typecheck
npm run build
npm test
```

三条都必须通过。另可用 `npx vite src/renderer --port 5174` 起本地静态服务自查（可选）。不要同时运行 `npm run dev`，主进程实现者会占用它。
