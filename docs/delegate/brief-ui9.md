# 任务说明书：v2.0 主界面重构（df-ui2）

## 背景

用户认为 v1.6 的界面"变化不大"。已用 ask-gpt 生成重设计概念图并存进仓库：`docs/product/ui-concept-v2.png`（竖版场记板 + 巨幅题材 + 竖向胶片脊柱 + 右栏放映/统计/镜头表）。设计系统写在 `DESIGN.md`，产品真相在 `PRODUCT.md`。场记板素材已生成：`docs/product/assets/clapper-strip.png`（2172×724 PNG，无文字）。

这次是**重构（replace），不是微调**：主界面的版式整体换成概念图那套。

## 必须保留的功能（不能丢，位置可以变）

1. 日期切换、搜索、采集状态点 —— 顶栏。
2. 日 / 周 切换 —— hero 右上角；周视图沿用现有实现。
3. 导出剧本 / 导出 PDF / 导出 EDL / 导出海报（四主题）—— 顶栏"导出▾"菜单。
4. 设置抽屉 —— 顶栏"设置"。
5. 对比两天、片场日历 —— 顶栏"···"菜单（或导出菜单旁）。
6. 播放 / 暂停 / 60x·600x·3600x / 进度条 / 时间码 —— 右栏"放映"。
7. 导演手记 —— hero 三指标下方一行（保持自动保存与字数）。
8. 高光三张卡 —— hero 剧照下方三张紧凑卡。
9. 镜头列表 —— 右栏"最近镜头"表；保留点击定位与键盘选择。
10. 项目汇总 —— 右栏"今日统计"下方一行（"项目：A 20 分 · B 5 分"）。
11. 放映态、片头卡、HUD 页面、海报/PDF/EDL 的既有逻辑 —— 不改行为，只跟随新配色与字阶。

## 脊柱（88px 竖向胶片）

- 一帧 = 10 分钟，24 小时共 144 帧，每帧高 24px；整条 3456px，放在可滚动容器里（`overflow-y: auto`，隐藏横向）。
- 画布只画可见范围（虚拟化）：监听滚动，按 `scrollTop ± 一屏` 重绘。
- 每帧：有素材 → 族色底 + 该 10 分钟内最长镜头的剧照缩略；无素材 → 斜纹暗格。左边 2px 族色边、右边齿孔。
- 右侧 16px 密度柱：每 10 分钟一桶，柱高按非空闲秒数。
- `现在` 标记：琥珀 1px 横线 + 右侧 `现在 14:36` 小标签（mono 10）。
- 顶部 `00:00`、底部 `24:00`。
- 点击某帧 → 定位到该 10 分钟内第一个镜头；滚轮滚动 = 平移时间视图；`Home/End` 跳顶/底。

## 视觉规格（照 DESIGN.md）

- 题材 128px：拉丁用 Bebas，中文用系统 900、字距 0.02em；无数据时 64px 的"未开镜"。
- 三指标：标签 10px mono 大写 dim，数值 28px plex mono；列间 1px 竖线；数值 `nowrap`。
- 右栏数字用 28px plex mono；表头 10px mono 大写 dim；行高 32px。
- 面板一律 1px 发丝线 + `--panel`，浮层 `--lift`，不用圆角大框（沿用 v1.6 的铬规范）。
- 场记板素材：`src/renderer/src/assets/clapper-strip.png`，用 CSS `background-image` + `object-fit` 思路（`background-size: cover; background-position: center 40%`），高 120px，底部 1px 发丝线 + 8% 暗角；素材很宽，注意别被拉变形。

## 实现顺序（每步跑 `npm run build`）

1. 骨架：顶栏 + 三列容器 + 右栏（放映/统计/最近镜头）接现有数据；hero 先放静态标题与数字。
2. hero：素材条、题材、当前窗口、三指标、剧照、手记、高光。
3. 脊柱：canvas + 虚拟化 + 点击/滚轮/键盘。
4. 菜单收敛：导出菜单、`···` 菜单（对比/日历/周）、设置入口；删掉旧版被替换的容器与样式。
5. 回归：放映态、片头卡、周视图、三个浮层、HUD 页面配色统一。

如果时间/上下文不够，**优先保证第 1–3 步完成且构建通过**，把未完成的第 4–5 步写进状态文件，不要留半成品代码。
